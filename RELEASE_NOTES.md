# Binaural Companion v0.1.0

First public Android release.

## Highlights

- Adds a quiet, locally generated stereo layer while Spotify or another media app continues playing.
- Includes Wind down, Calm focus, Deep work, Reset, experimental 40 Hz, and neutral 0 Hz modes.
- Supports steady differences or gradual 0-40 Hz glides around a carrier-centered stereo pair.
- Offers an optional Gateway-inspired preparation using ordinary intention, breathing, and relaxation practices.
- Stores optional before/after calm, focus, and energy ratings only on the device.
- Uses no microphone, network, analytics, account, or audio-capture permission.

## Installation

1. Download `binaural-companion-v0.1.0.apk` from the release assets.
2. Allow your browser or file manager to install apps from this source when Android asks.
3. Install the APK and connect stereo headphones.
4. Keep the generated layer faint beneath music and stop if you feel discomfort.
